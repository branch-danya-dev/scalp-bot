Для измерения missed opportunities нужны уникальные кандидаты, их доступные на момент решения признаки и полный последующий исполнимый путь. Текущие decision snapshots и hindsight-движения не заменяют это. Данные подходят для диагностики и фиксации гипотез; P0/P1 ещё не пройдены.

## Изменение после анализа

Добавлен `scalp_bot/run_manifest.py`. При Start записывается manifest: явный allowlist всей текущей несекретной Settings-конфигурации, её SHA-256, фактические enabled/evidence-only/tradeable стратегии, публичная research policy, версии manifest/record/execution model и fingerprint исходников. Manifest ID уникален для Start; Summary и изменения стратегий ссылаются на него. Старый частичный `config` сохранён для совместимости.

Новые поля Settings не сериализуются автоматически: неизвестные имена перечисляются отдельно без значений, регрессия требует явной классификации. API key/secret исключены даже из hash. Политика публичных полей требует не помещать credentials в URL, label или другие несекретные настройки.

Ограничения provenance: hash относится к исходникам **на диске при Start**, не доказывает идентичность ранее загруженного Python-кода; нельзя редактировать код работающего процесса. Git dirty учитывает tracked-файлы, fingerprint Python-кода включает и новые файлы. Полный dependency/environment fingerprint и автоматическая сверка manifest валидатором ещё не реализованы. У старых сессий manifest неизвестен; новый код не приписывает его задним числом.

Торговые правила и временная база пока не изменены. 511 тестов прошли; единственное предупреждение — запрет записи pytest cache, не ошибка теста. Новый сервер или торговый прогон не запускался.
