# P0 baseline v1 — 12 часов наблюдения

Статус: пользователь завершил сеанс 24–25 сентября; [результат разобран](p0-baseline-results-2026-09-25.md). Инструкция сохранена для воспроизводимости. Повторять неизменный baseline до технических исправлений сейчас не требуется.

Цель: получить непрерывную запись неизменного baseline для проверки clock/data integrity, отказов, входов и выходов. Runtime clock ещё не исправлен; возможные нарушения валидатора являются предметом исследования. Это не сравнительный эксперимент исправленной стратегии и не подтверждение прибыльности.

12 часов — ограниченный интервал для наблюдения разных периодов активности и накопления событий. Он не гарантирует заданное число сделок или статистическую достаточность. Следующий шаг определяется качеством записи, а не знаком PnL.

## Запуск из PowerShell

```powershell
cd G:\scalp-bot
.\scripts\run-p0-baseline-12h.ps1
```

Если старый сервер занимает порт 8000, сначала штатно остановить его. Launcher выполнит изолированные тесты и проверку доступности рынка, затем запустит сервер. Открыть `http://127.0.0.1:8000/` и нажать Start. Отсчёт 43 200 секунд начинается с Start, а не с запуска терминала.

Не переключать стратегии и не менять код/профиль в этом процессе. Оставить компьютер включённым без сна и терминал открытым. Запись многогигабайтная: по предыдущей сессии ориентир порядка 30 ГБ за 12 часов, фактический объём зависит от активности и событий; предусмотреть запас.

## Конфигурация

- `.env.example` + `.env.research-p0-baseline-12h`; локальный `.env` отключён.
- Breakout и rejection включены; trend выключен; density только evidence.
- Staged adds breakout/rejection выключены. Остальные торговые и risk параметры наследуются из baseline.
- Комиссии фиксированы для сравнимой paper-модели: taker 0.055%, maker 0.020%; дополнительное slippage 1 б.п. Account fee lookup выключен.
- Research frames каждые 3 секунды, лента `delta_v1`; replay frames 5/20 секунд без дублирования ленты.
- Prometheus включён, внешняя OTel-инфраструктура не требуется.
- Результаты: `data/sessions/session-*.jsonl`, label `research-p0-baseline-v1-12h`.

## Завершение

По таймеру бот закрывает paper-позиции, отменяет ожидающие заявки и пишет run_summary. Сервер продолжает работу и может дописывать рынок. После завершения торговли остановить сервер через Ctrl+C для финализации файла.

Проверка последнего файла после остановки сервера:

```powershell
$session = Get-ChildItem .\data\sessions\session-*.jsonl | Sort-Object LastWriteTime -Descending | Select-Object -First 1
$report = Join-Path $session.DirectoryName ($session.BaseName + '-integrity.json')
.\.venv\Scripts\python.exe .\scripts\validate-session.py $session.FullName --output $report
```

Проверить, что выбран файл данного сеанса. Output не должен существовать: валидатор сохраняет прошлые evidence. Rejected означает обнаруженные нарушения; их причины содержатся в JSON. Исходный JSONL сохранить без редактирования. Не требуется загружать многогигабайтный файл в чат: он доступен локально для следующего анализа.

После получения данных: проверить время/gaps/recorder и неизменность стратегий, сверить PnL, выделить причинные эпизоды. Полный manifest и runtime clock остаются открытыми задачами P0-03/P0-04; этот профиль их не заменяет.
