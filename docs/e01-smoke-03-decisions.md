# Smoke-03: готовые сигналы, отказы и незавершённые пробои

Дата: 2026-09-25. Источник — завершённая часть smoke-03; исходные журналы не изменялись. Новый сетевой прогон не выполнялся. Торговые правила и профиль не менялись.

## Что установлено

В торговом окне каждый портфель наблюдал **34 поколения уровней**, из них 25 появлялись в ARMED, 14 в BREAK. Готовый breakout-сигнал был **один**: BTC short. Это не последовательная воронка с непересекающимися стадиями: состояния повторяются, сбрасываются и могут быть пропущены в журнале изменений.

Baseline открыл этот BTC, candidate отклонил по `e01_foreign_obstacle_before_first_take`. Остальные пять готовых сигналов — rejection: четыре одинаково открыты, один BTC одинаково заблокирован. Итого шесть уникальных готовых setup, один различающийся факт открытия. Ключ — symbol/strategy/side/setupId; повторные оценки и повторное использование того же поколения не увеличивают число уникальных кандидатов. Исполненные открытия не эквивалентны всем разрешениям/заявкам арбитра.

1197 baseline и 1216 candidate записей WAIT по breakout — изменения решений, а не независимые возможности входа. Количество отказов на каждом timer tick из них восстановить нельзя. Порог E01 «100 кандидатов» сейчас заполнен одним готовым сигналом, а не 34 уровнями или сотнями WAIT.

## Фактические отказы арбитра

**BTC breakout short.** Встречная support-зона 83423.60–83718.10 уже охватывала цену предполагаемого входа 83574.75; это другое поколение относительно пробиваемого уровня. До первой фиксации требовалось движение к 83096.37. За следующие пять минут лента опускалась лишь до 83542.00: максимум +3.92 bps в сторону short, движение против — до 25.52 bps. Ни первая фиксация, ни цель не достигнуты. Baseline реально закрыл сделку через ~110 секунд по возврату внутрь зоны: net −1.07816 USDT. Фильтр помог в этом одном наблюдении.

**BTC rejection short**, отклонён обоими портфелями обычным структурным фильтром. Цена решения 83730.35, намеченный стоп 83788.50. Лента пересекла этот стоп через 50.62 s; первая фиксация и цель за пять минут не достигнуты. Максимальное движение в пользу short всего 0.39 bps, против — 16.12 bps. Это наблюдение поддерживает отказ; гипотетическая сделка с полным управлением позицией не моделировалась.

## Что произошло до готового сигнала

Для **всех 14**, без отбора по результату, взято первое зарегистрированное WAIT/BREAK после Start на symbol/zoneGeneration. Направление: support → short, resistance → long. Цена отсчёта — записанная marketContext.lastPrice. Окна 60/180/300 s выбраны для диагностического разбора после прогона; это не заранее зарегистрированный тест стратегии.

Нельзя объявить положительные экстремумы «упущенной прибылью»: исполнение, издержки, стоп, динамические выходы и капитал не воспроизведены.

### Конкретная цепочка ZEC

- Первый BREAK: lastPrice 1580.89, направленный поток и sustainedResponseReady=true, hold ещё 0 s; требуется 8 s без retest.
- Через 8.1135 s: lastPrice 1577.99; отказ из-за stopDistancePct=0.00725126 (**0.7251%**) при `LevelBreakoutStrategy.max_stop_pct=0.006` (**0.6%**).
- Stop рассчитывается за противоположным краем всей зоны плюс buffer. Это совместное ограничение момента подтверждения и геометрии стопа, а не отказ E01: до арбитра готовый сигнал не дошёл.
- Позже по тому же поколению чередуются отказ по стопу, неподтверждённый локальный поток, absorption и ARMED. Через 69.28 s стоп всё ещё 0.6409%, выше лимита.

У XRP первый BREAK отклонён из-за недостаточных pressure/pre-state/flow; через ~0.20 s записан поиск без подходящего зрелого уровня. У DOGE short -3877 первый отказ — поглощение потока без достаточного направленного движения. Это разные причины: один общий переключатель «больше входов» не решает их.

## Решение и следующий инкремент

E01 оставить без изменения: на этом интервале он не является причиной массовых пропусков, поскольку получил только один breakout. Основной участок для исследования — переход BREAK → готовый вход.

Следующий шаг: детерминированно воспроизвести участок ZEC от ARMED до отказа по стопу, восстановить доступные на каждом шаге варианты инвалидации и проверить, существует ли более ранний подтверждённый вход в пределах прежнего риска. Затем проверить ту же гипотезу на отрицательных случаях из таблицы. Не повышать 0.6% и не сокращать 8 s только ради прохождения ZEC; изменение возможно лишь как отдельный default-off эксперимент с фиксированным правилом. DOGE/XRP требуют отдельной проверки сохранения гипотезы и направленного потока.

72h пока не запускать: суточные метрики, ограниченное по памяти воспроизведение и проверка исправленного shutdown остаются открытыми. Эти данные уже использованы для диагностики, поэтому будущую новую гипотезу нельзя подтверждать на них как на нетронутой выборке.

## Воспроизводимость разбора

`scripts/analyze-e01-decisions.py` читает журналы потоково, проверяет source archive по всем manifest hashes, привязку manifests к header, всю цепочку 1091002 inputs и footer, соответствие закрытых сделок результату. SHA-256 каждого output ledger записан в отчёт. Это анализ исторических данных; captured code не исполняется, current-source parity не заявляется и replay guards не отключаются.

```powershell
.\.venv\Scripts\python.exe scripts/analyze-e01-decisions.py data\e01-smoke-03 --feed-name feed-sealed-prefix.jsonl --source-archive data\e01-smoke-03\source-at-capture.zip --output data\e01-smoke-03\decision-analysis-repeat.json
```

Артефакты: `decision-analysis-with-breaks.json` — полный разбор; `decision-analysis.json` — первоначальный разбор только готовых сигналов; `break-reason-timeline.json` — 279 изменений причин в пяти минутах после первых BREAK, baseline, с hash источника. Существующий output скрипт не перезаписывает.

Лента отбирается по receipt_mono_ns после диагностической отметки, поэтому ранее полученные, но задержанные очередью сообщения не считаются новым движением. Неполные окна отмечаются явно и не получают horizon return; возраст последней цены сохранён. Это last-trade данные, а не исполнимые bid/ask; покрытие ограничено записанным набором активных инструментов. Полный replay и измерение всех прибыльных возможностей рынка не выполнены.

Проверки: **23 passed за 21.88 s**, включая 6 новых проверок диагностики — направления, границы окон, неполный горизонт, дедупликация, интеграционный capture и отклонение повреждённой записи/архива. Торговой код не изменён; полный набор повторно не запускался (предыдущий результат 806 passed).
