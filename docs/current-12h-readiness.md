# Исправление продолжения назначения и текущий 12-часовой paper-профиль

База: `80b836621327488af0e550aaa47226e584a2e4ed`.
Поручение владельца: исправить остаточный дефект ASSIGNED и подготовить проверку
текущего состава на 12 часов. Сам рыночный запуск при подготовке не выполняется.

## Исправление

`ScenarioRouter._unprepared_object_invalid` повторно проверяет пригодность именно
назначенного объекта по `can_prepare` владельца, но только для пустого ASSIGNED:
нет начала подготовки, замороженного плана, заявки или позиции. Если получен
пригодный для оценки контекст и тот же уровень/линия больше не может быть
подготовлен, назначение завершается с `assigned_object_no_longer_preparable`.
Следующее наблюдение может назначить независимый объект без нового таймера.
Использованным остаётся только исходный эпизод; отказ нельзя обойти сменой стратегии.

Отсутствие кандидата из-за ранжирования, изменения радиуса или нехватки данных
не считается отменой. PREPARED/ARMED/ORDER_PENDING/IN_POSITION продолжают жить
по собственным правилам. Объект, исчезнувший из структуры, как и ранее, имеет
отдельную причину отмены. Порогов входа, стопов, целей и плеча это изменение не касается.

В тесте с настоящим playbook закреплённый пробой продолжает работу после перехода
уровня в broken и входит по достаточному причинному событию без нового hold.
Тот же переход у пустого назначения освобождает монету. Проверены long и short,
а также потеря пригодности молодого rejection-уровня и трендовой линии.

## Профиль current-12h

Новый launcher: `scripts/run-paper-capture-current-12h.ps1`.
Файл настроек: `.env.paper-capture-current-12h` поверх `.env.example`.
Он очищает унаследованные SCALP-переменные и отключает локальный `.env` на время
запуска, затем восстанавливает окружение. Локальный `.env` не переписывается.

Старый `run-paper-capture-12h.ps1` / `all-12h` сохранён: он включает trend и beta.
**Для назначенного сейчас прогона использовать новый current-12h, не старый all-12h.**

| Условие | Значение |
|---|---|
| Длительность | 43200 секунд от нажатия Start, включая защитные паузы |
| Владельцы сделок | Пробой и отбой |
| Плотность | Evidence-only |
| Trend / BETA | Выключены; переключение состава во время capture заблокировано |
| Paper-баланс | 1000 USDT |
| Структурный риск | 0,5% |
| Максимальная плановая all-in потеря одной сделки | 1,25% |
| Совокупный плановый риск | 2% |
| Лимиты экспозиции | До 5x на позицию, 10x на портфель; до 4 позиций |
| Расходы | Taker 0,055%, maker 0,02%, резерв slippage 1 bps |
| Экономика | Hard net-R = 1; winner-cost-share включён, максимум 0,35 |
| Мягкие min-profit / net-R gates | Выключены, как в текущем checked-in часовом профиле |
| Общий стоп убытка сессии | Выключен, как в исходном профиле; это PAPER-исследование |
| Диск до старта | Не менее 100 ГиБ; это минимальный допуск, не прогноз объёма |
| Защита записи | Ошибка/потеря строк или менее 5 ГиБ останавливает paper |
| Финансовый экзамен +10% | Отсутствует |

Плановые лимиты не являются гарантией фактического максимального убытка.
Плечо бирже не задаётся: речь об экспозиции paper-портфеля. Выбор этого профиля
не означает сохранение неизвестных пользовательских изменений локального `.env`:
используется зафиксированный checked-in baseline, показатели выводятся до старта
и попадают в terminal.log и манифест. Размеры и правила сопоставлены с current-1h
автоматическим тестом; отличаются только название и длительность.

## Запуск на Windows

Остановить прежний процесс бота перед обновлением. Сохранить локальные изменения;
не использовать reset/clean. В PowerShell:

```powershell
git -C G:\scalp-bot fetch origin
git -C G:\scalp-bot switch main
git -C G:\scalp-bot pull --ff-only origin main
Set-Location G:\scalp-bot
.\scripts\run-paper-capture-current-12h.ps1 -Check
.\scripts\run-paper-capture-current-12h.ps1
```

`-Check` проверяет профиль и реальный свободный диск без подключения к бирже.
Команда без `-Check` повторяет профиль, выполняет полный тестовый preflight,
проверяет доступность публичных данных Bybit и запускает UI в видимом терминале.
Открыть `http://127.0.0.1:8000/`, дождаться готовности данных, нажать Start один раз.
В интерфейсе должен быть профиль current-12h и 12 часов, а не 24h/старый all-12h.
Не обновлять исходники и зависимости до завершения проверки записи. Отключить сон
компьютера; терминал и сетевое соединение оставить работающими.

По сроку бот отменяет ожидающие заявки, закрывает paper-позиции, пишет итог и
автоматически завершает capture. Дождаться «Запись сохранена». Ручной Stop тоже
сохраняет запись, но такой запуск не является полными 12 часами. Не завершать
процесс принудительно: наличие footer не гарантируется после убийства процесса.

## Проверка и материалы после остановки

```powershell
.\scripts\check-paper-capture.ps1 -Profile current-12h
```

Команда выбирает последнюю `data/paper-captures/current-12h-*` и выполняет полный
локальный baseline replay без Bybit. При нескольких запусках передать нужную
папку явно: `-Directory "G:\scalp-bot\data\paper-captures\current-12h-..."`.
Для SQLite-индекса нужны дополнительное место и время. Проверку выполнять на
тех же исходниках/зависимостях. Не обновлять репозиторий до её завершения.

Для первичного разбора передать `capture-check.json`, `capture.json` и `terminal.log`.
Целиком сохранить папку: обычный session JSONL, полный сжатый журнал входов,
`capture-manifest.json` и `source-at-capture.zip` необходимы для точного анализа.
Сырые записи не коммитить и не удалять ради компактного отчёта.

Оцениваются net и комиссии, состав и причины сделок/отказов, освобождение
непригодных ASSIGNED, своевременность входов и сопровождение. Успешное сохранение
и replay не означают положительный PnL. Профиль проверяет только включённый состав;
результат не характеризует отдельно выключенные стратегии.

## Локальная проверка изменений

`tests/test_scenario_continuation.py`: исходные 28 регрессий дали 8 failed / 20 passed
до исправления; после — 32 passed, включая настоящий pinned breakout и интеграцию
с движком. `tests/test_current_12h_profile.py`: 9 проверок. В сумме — 41 passed.
Проверка 43200 секунд выполнена ускоренным переводом логических часов на синтетике:
реальная позиция закрывается, capture сохраняется и полностью воспроизводится.
Это не 12-часовая рыночная нагрузка и не заявление о доходности.

Полный локальный preflight: **1132 passed за 60.18 s**, Python 3.13.5.
Первый вызов полного набора прерван лимитом рабочей среды; повторный полный
запуск завершён, журналы обоих сохранены. Результат GitHub CI фиксируется в PR. Новый рыночный запуск —
только запуском владельца по командам выше; при подготовке он не выполнялся.
