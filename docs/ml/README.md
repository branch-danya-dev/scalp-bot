Git tree `a5781b1659f962b2c0724633c3b93de37f5d0cf9`.

**Состояние: M0 — контракты и план. Обученной модели, inference worker,
обучающего датасета и подключения к ордерам пока нет.**

Цель — проверить, даёт ли локальный предиктор импульсного продолжения полезные
входы, не покрытые обычными playbooks. Это не обещание прибыли и не замена
исполнения, риска или обычных стратегий разговорной моделью.

## Что согласовано в обсуждении

Общий scanner, активные монеты, исходные данные, капитал и исполнительный движок.
Обычные стратегии не ждут ML; модель в перспективе работает отдельным локальным
процессом. Два источника решений, но один владелец заявки/позиции на символ.
ML получает собственный сценарий `trend_impulse_ml`, не маскирует вход под breakout.
Плотности/объёмы/формирующиеся свечи — числовые признаки, а не картинки для LLM.
Прогноз не становится фактом рынка и не перерисовывает подтверждённые уровни.

Начальная политика из последнего обсуждения: готовое обычное решение имеет
приоритет; готовый ML-план может заменить только наблюдение/подготовку без заявки,
если проходит ту же экономику. Reservation, отправленная заявка, частичный fill,
отмена и неопределённое исполнение уже означают занятость, даже без позиции в UI.
Модель не обходит предыдущий отказ риска переименованием того же эпизода.

**Идущий current-12h не изменять.** По сообщению владельца он запущен; его текущий
статус/результат удалённо не проверен. Не переключать рабочую копию, не устанавливать
ML-зависимости рядом с работающим процессом и не запускать обучение на его ресурсах.
В этой ветке меняются только новые изолированные модули/тесты и документация.
В `Settings`, engine, scanner, broker, capture-профили и реестр стратегий M0 не входит.

## Что можно выполнить сейчас

В отдельной рабочей копии, не в каталоге идущего capture:

```powershell
python -m scalp_bot.ml
python -m pytest tests/ml -q
```

Первая команда только печатает статус M0 и всегда сообщает отсутствие обученной
модели/торговых полномочий. Она не читает `.env`, не подключается к сети и не выдаёт
выдуманные прогнозы. Тесты проверяют сообщения и чистую таблицу выбора предложений,
а не качество модели и не межпроцессную интеграцию.

Файл [impulse-v1.json](../../research/ml/impulse-v1.json) — описание исследования,
**не конфигурация запуска и не разрешение торговли**. Следующий шаг — M1: инвентарь
проверенных записей и причинный датасет всех наблюдавшихся рынков, не только сделок.
